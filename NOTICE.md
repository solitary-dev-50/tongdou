# TongDou Notice

This notice defines the current license scope and brand boundary for the TongDou public repository.

## Open Hardware License Scope

The root `LICENSE` file contains the CERN Open Hardware Licence Version 2 - Permissive, also known as `CERN-OHL-P-2.0`.

At the current stage, `CERN-OHL-P-2.0` applies only to schematic PDF files in this repository that are explicitly marked as open hardware materials:

- `hardware/schematic/tongdou-pcb-v8-schematic-main-control.pdf`
- `hardware/schematic/tongdou-pcb-v8-schematic-power.pdf`

No other material is included in the open hardware license unless a future release clearly says so.

## Materials Not Covered By The Open Hardware License

The following materials are not included in the current `CERN-OHL-P-2.0` grant:

- Photos
- Videos
- README files and general documentation
- Website content
- The TongDou name
- TongDou logo
- TongDou character identity and visual design
- Official audio files
- Promotional materials
- Packaging

All rights to those materials are reserved unless a separate license is provided.

## Materials Not Yet Publicly Licensed

The following materials are not currently publicly released or publicly licensed:

- Editable PCB source files
- Gerber files
- BOM files
- PNP, CPL, or pick-and-place files
- Mechanical files
- Soldering fixtures
- Firmware
- Production test materials
- Cost, supply-chain, or purchasing lists
- Private backend configuration, keys, tokens, secrets, or test data

These materials may be reviewed for phased release later. No specific release date is promised.

## Brand And Official Product Boundary

Third parties must not present their products as official TongDou products.

Third parties must not claim official TongDou certification, approval, endorsement, partnership, or crowdfunding participation unless that status is announced through the official TongDou website:

https://gettongdou.com

Official TongDou products and crowdfunding campaigns will only be announced through https://gettongdou.com
