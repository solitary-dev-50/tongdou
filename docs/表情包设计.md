# 表情包设计

这份文档规定铜豆的表情资源包怎么组织、怎么命名、怎么替换。

它和 `docs/表情系统.md` 的分工是：

- `表情系统.md`：规定什么时候用什么表情、切换节奏和优先级。
- `表情包设计.md`：规定这些表情资源本身怎么做、怎么打包、怎么让用户以后替换。

大白话说：

> 表情系统是导演，表情包是演员的脸。

---

## 1. 总原则

铜豆的主表情必须是自己的“小眼神”，不是通用图标。

第一版屏幕是 `0.96` 寸 `OLED`，所以表情包要遵守：

- 黑白优先。
- 低帧数。
- 粗线条。
- 少文字。
- 一眼能看懂。
- 不追求大动态表情。

第一版不直接搬板机的动态 `Emote` 表情包。

---

## 2. Font Awesome 和表情包分工

| 内容 | 建议资源 | 用途 |
| --- | --- | --- |
| 系统状态 | Font Awesome 图标 | WiFi、电量、充电、静音、设置 |
| 角色表情 | 自定义 OLED 表情包 | 睁眼、眯眼、翻白眼、无辜眼、委屈眼 |
| 剧情动画 | 多帧小眼神 | 被咖啡呛到、深夜下班提醒、装怂 |
| 未来扩展 | 可替换表情包 | 温柔版、嘴欠版、戏精版 |

原则：

- Font Awesome 是状态标识，不是铜豆的脸。
- 自定义表情包才是铜豆的脸。
- 不要用通用图标代替核心眼神。

---

## 3. 第一版必须有的表情资源

第一版至少准备这些表情：

| 表情编号 | 用途 | 建议帧数 |
| --- | --- | --- |
| `face_sleep` | 睡觉眼、低功耗 | 1 到 2 帧 |
| `face_wake` | 睁眼、上线 | 3 到 4 帧 |
| `face_listen` | 倾听、等待命令 | 1 到 2 帧 |
| `face_smile` | 完成奖励 | 1 到 2 帧 |
| `face_serious` | 会议、重要提醒 | 1 帧 |
| `face_roll_eyes` | 推迟、吐槽 | 2 到 3 帧 |
| `face_wronged` | 安静模式、被凶 | 1 到 2 帧 |
| `face_tired` | 装累、低电量 | 1 到 2 帧 |
| `face_shock` | 拍桌子、惊吓 | 2 帧 |
| `face_squint` | 深夜下班提醒、审问 | 1 到 2 帧 |
| `face_innocent` | 说完装怂、无辜 | 1 到 2 帧 |
| `face_confused` | 识别失败、没听懂 | 2 到 3 帧 |

---

## 4. 资源命名规则

建议资源名按这个格式：

```txt
face_<表情名>_<帧序号>
```

例如：

```txt
face_wake_01
face_wake_02
face_wake_03
face_roll_eyes_01
face_roll_eyes_02
```

如果后续做资源文件，可以用：

```txt
faces/default/face_wake_01.bmp
faces/default/face_wake_02.bmp
faces/dramatic/face_squint_01.bmp
```

第一版也可以不使用图片文件，直接在代码里画线条。  
但表情编号和资源命名要先统一，避免后面换包时推倒重来。

---

## 5. 表情包风格分层

后续网页配置可以支持不同表情包：

| 表情包 | 风格 |
| --- | --- |
| `default` | 默认铜豆，小嘴欠，小温暖 |
| `gentle` | 温柔提醒，少翻白眼 |
| `workmate` | 打工搭子，嘴欠但克制 |
| `dramatic` | 戏精模式，表情更夸张 |

注意：

- 表情包可以换风格，但不能换掉铜豆人格宪法。
- 任何表情包都不能让铜豆变成审判用户的机器。

---

## 6. 显示实现路线

第一版建议：

```txt
FaceAction -> OLED 小眼神绘制 -> 少量帧切换
```

不要一开始就做：

```txt
FaceAction -> GIF / Emote 大动画
```

原因：

- `0.96` 寸 `OLED` 显示区域小。
- 当前屏幕走 `I2C`。
- 低帧数眼神更稳、更省电、更符合铜豆。

未来如果换成更大或更快的屏幕，可以升级为：

```txt
FaceAction -> 表情包资源 -> 动画播放
```

---

## 7. 参考小智板机适配

小智板机适配里有几种表情资源思路：

- Font Awesome 图标：适合系统状态。
- Twemoji 静态表情：适合通用 emoji 图片。
- 自定义 `emoji_collection`：适合外部表情资源包。
- GIF 动画：适合较复杂动态表情。
- `esp_emote_expression`：适合更重的动态表情引擎。

铜豆第一版只借鉴它的分层思想：

```txt
表情名 -> 表情资源集合 -> 显示实现
```

不直接搬它的动态表情引擎。

---

## 8. 检查清单

新增或修改表情包前检查：

1. 这个表情在 `0.96` 寸屏上清楚吗？
2. 不看台词，用户能不能看懂情绪？
3. 是否能和灯光、电机动作配合？
4. 是否会太吵、太闪、太频繁？
5. 是否符合“嘴上很凶，动作很怂”？
6. 是否有安静模式版本？
7. 是否和 `docs/人格宪法.md` 冲突？
