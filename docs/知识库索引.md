# 知识库索引

这份文档是铜豆项目的资料入口。

遇到问题时，先看这里，再去对应文档。不要在项目里乱翻、乱猜、乱补。

## 必读顺序

每次开始工作前，建议按这个顺序看：

1. `AGENTS.md`
2. `docs/知识库索引.md`
3. `docs/硬件说明.md`
4. 和本次任务直接相关的专项文档

## 当前路线

铜豆当前主线是：

- `ESP32-S3` 主控
- `INMP441` I2S 单麦克风
- `NS4168` I2S 数字功放
- OLED 表情屏
- WS2812 单颗灯
- AT8833 双电机驱动
- LD2412 毫米波雷达
- TP4057 充电与电池检测
- 复用 JiShi 的系统编排、网页配置、音频、联网和 MCP 相关软件资产

已经废弃的旧硬件路线不再进入主线文档。

## JiShi 复用资料

### `docs/JiShi资产复用评估.md`

用途：

- 查看 JiShi 哪些模块能给铜豆复用。
- 区分直接复用、改造复用和不复用。
- 避免把 JiShi 整包硬搬。

### `docs/JiShi迁移步骤.md`

用途：

- 查看 JiShi 迁移到铜豆的具体执行顺序。

什么时候看：

- 每次准备从 JiShi 搬代码前。
- 每次准备新增系统编排、网页诊断、MCP、实时音频能力前。
