# 知识库索引

这份文档是铜豆项目的资料入口。

遇到问题时，先看这里，再去对应文档。不要在项目里乱翻、乱猜、乱补。

## 必读顺序

每次开始工作前，建议按这个顺序看：

1. `AGENTS.md`
2. `docs/知识库索引.md`
3. `docs/硬件说明.md`
4. 和本次任务直接相关的专项文档

## 当前路线

铜豆当前主线是：

- `ESP32-S3` 主控
- `IM72D128V01XTMA1` PDM 单麦克风
- `NS4168` I2S 数字功放
- OLED 表情屏
- SK6812-EC20 单颗灯
- AT8833CT 双电机驱动，`nFAULT` 故障输出接 `IO37`
- QMI8658A 六轴惯性传感器
- 铜豆 Logo 触摸输入，接 `IO4`
- LD2412 毫米波雷达
- TP4057 充电与电池检测
- 复用 JiShi 的系统编排、网页配置、音频、联网和 MCP 相关软件资产

当前回板验证对象是 V9 PCB。V9 在原有硬件基础上增加 `QMI8658A` 六轴惯性传感器和铜豆 Logo 触摸输入，Logo 触摸接 `IO4`，`QMI8658A` 与 OLED 共用 `IO6/IO7` 的 I2C 总线；电机驱动 `AT8833CT nFAULT` 故障输出已接 `IO37`。

当前公开制造资料仍是 `hardware/pcb/tongdou-pcb-v8/`，V9 制造资料需要完成回板验证后再整理公开。

第一版不安装复位轻触按钮，也没有单独预留 `RSET/EN` 触点，日常重启通过电源开关完成。

后续资料以当前主线为准。

### `docs/V9_PCB回板验证清单.md`

用途：

- 专门验证 V9 新增的 Logo 触摸和 `QMI8658A`。
- 确认 OLED 与 `QMI8658A` 共用 I2C 后仍然稳定。
- 记录触摸误触、姿态数据、敲击和倾倒检测的初始测试步骤。
- 当前已记录 `QMI8658A` 板级识别、`Z` 轴偏航判断，以及 `/motor` 陀螺仪空载直行测试结论。

什么时候看：

- V9 PCB 第一次上电后。
- 准备写 `LogoTouchInput` 或 `ImuSensor` 前。
- 触摸或姿态数据不稳定时。
