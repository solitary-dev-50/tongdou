# 铜豆正式固件：收货配网图文教程

适用范围：已装好正式应用固件的铜豆，配合 v0.1.2 测试版服务器，在 Windows 电脑上运行本地服务。按 2026-09-13 工作区代码和交付说明核对。

**收到货后不用重新刷机。先启动服务器，再用手机给铜豆联网，最后绑定设备。**

**交付入口：[单网页图文教程](tongdou-setup.html)。** 下载这一个网页文件，用浏览器打开即可。英文、中文、俄语在顶部切换，每次打开默认英文；无需外部图片、字体或网络资源。切换教程语言不会改变设备语言。界面示意中的网络名、地址和验证码不是用户实际设置。

本文保留中文流程依据，面向用户的图文内容统一在单网页维护，不再生成 PDF 或中文图片版。

## 1. 准备好铜豆、手机和服务器电脑


准备这些东西：

1. 已装好正式固件的铜豆，放在平稳、远离桌边的地方。
2. 一部能连接无线网络、打开浏览器的手机。
3. 家里的 **2.4 GHz 无线网络**及密码。铜豆不支持仅有 5 GHz 的网络；双频同名网络只要启用了 2.4 GHz 即可。
4. 一台运行铜豆服务器的 Windows 电脑，以及随交付提供的服务器压缩包。电脑可以用网线或无线网络接同一台路由器。

将铜豆接到 5V 的 USB-C（椭圆形充电接口）电源，再打开电源开关。先启动下节的服务器，再操作手机配网。当前本地服务器方案需要电脑保持开机、服务保持运行，才能进行联网语音对话。

如果交付方已经提供了可用服务器地址和绑定入口，直接使用交付方给出的信息，从第 3 节开始；不要自行把地址改成本文示例。

## 2. 先启动电脑上的铜豆服务器


1. 将随包服务器压缩包完整解压到普通文件夹，不要在压缩包预览窗口里运行。
2. 安装并打开 **Docker Desktop（运行服务器所需的软件）**，等它的运行引擎启动完成；使用期间保持运行。
3. 在解压后的文件夹里双击 `START_TONGDOU_SERVER.bat`（启动铜豆服务器）。第一次启动要下载和构建组件，需要联网，可能等待数分钟。
4. 等窗口显示 `SUCCESS`（启动成功），保留启动窗口。
5. 记下窗口里的 **TongDou device Server address（填写给铜豆的服务器地址）**。有的界面将它称为 **TongDou LAN server（铜豆局域网服务器）**。
6. 在服务器电脑打开管理页面，默认是 `http://localhost:8102`。首次使用先注册、登录，创建或选择一个铜豆智能体，也就是负责和设备对话的角色。
7. 为这个角色配置并保存可用的语音识别、对话模型、语音合成服务：分别负责“听懂你”“生成回答”“把回答念出来”。使用交付方给出的配置说明或自己可用的服务凭据；测试包不内置通用可用密钥。已经配置好的可以跳过这一步。

**填写给铜豆的地址**看起来像 `http://192.168.1.20:8102`，其中的数字以你启动窗口实际显示为准。完整保留 `http://` 和末尾端口号；默认是 `8102`，定制包以启动窗口为准。

`localhost` 和 `127.0.0.1` 都表示“当前这台设备自己”。它们只能用于相应的电脑本机访问，不能填到铜豆的服务器地址框。

若 Windows 防火墙弹出提示，为 Docker 或铜豆服务器允许“专用网络”访问。电脑和铜豆应处于可互相访问的家庭网络，避免使用隔离设备的访客网络。

## 3. 手机连接铜豆，再填写三项信息


1. 铜豆进入配网模式后，小屏幕会显示连接 **`TongDou-Setup`（铜豆配网热点）** 的二维码。可先用手机自带相机或系统扫码功能尝试扫码，并确认加入网络。屏幕太小，扫码效果仍待安卓和苹果手机实机验收；扫不出来时，打开手机“设置 → 无线网络”，手动连接 **`TongDou-Setup`**。这个热点**不需要密码**。微信扫一扫能否直接入网取决于手机和微信版本，不作为唯一入口。
2. 手机若提示“无互联网连接”，选择“仍然连接”或“保留连接”；不同手机文字略有不同。这一步是手机直连铜豆，暂时不能通过铜豆热点上网属于正常现象。
3. 若没有自动弹出页面，打开浏览器，在顶部地址栏完整输入 **`http://192.168.4.1/`**，不要填进搜索框。
4. 页面若为英文，可在顶部 **Language（语言）**中选“中文”。默认测试包可能使用英国英语；也可以照下面的中英文对照先完成配网。
5. 找到 **“连接和时间”** 区域，点击 **“扫描附近 WiFi”**，选择家里的无线网络；没有扫到时，确认网络已开启 2.4 GHz，也可准确手填网络名称。
6. 填好下表三项，点击 **“保存并连接”**，等待铜豆连接。

| 页面项目 | 应该填什么 |
| --- | --- |
| WiFi 名称 / WiFi name（无线网络名称） | 家里路由器的无线网络名称；不是 TongDou-Setup |
| WiFi 密码 / WiFi password（无线网络密码） | 上面这个家庭网络的密码；注意大小写和多余空格 |
| 铜豆服务器地址 / TongDou server address | 第 2 节启动窗口给出的完整设备地址；不要照抄示例数字 |

英文按钮：**Scan nearby WiFi = 扫描附近无线网络；Save and connect = 保存并连接。**

看到“已保存，铜豆马上连接 WiFi。”只表示资料已经保存，**还不代表联网和绑定都成功**。点“刷新状态”，确认网络显示“已连接”。新填写的网络如果连接失败，约 12 秒后会重新进入配网模式并显示二维码；重新连接热点，核对密码后再保存。二维码只负责连接铜豆热点，连上后仍要打开 `http://192.168.4.1/` 填写信息。

铜豆最多保存 **8 组无线网络**。每到一个新地点配一次；以后回到已经保存过的地点，开机时会自动寻找并尝试连接，不会因为保存新地点就忘掉旧地点。每组还保存当时填写的服务器地址，连上后会切回对应地址。控制台可查看和删除已保存的网络；同名网络重新保存会更新密码和服务器地址。只有保存的网络都连不上时，才开启配网热点。

## 4. 绑定设备，试着和铜豆说句话


1. 网络显示“已连接”后，将手机切回家里的无线网络。以后可尝试用 `http://tongdou.local/` 打开铜豆本机控制台；打不开时，使用配网页“状态 → 地址”中显示的铜豆实际地址。地址以你这台铜豆为准。
2. 铜豆连到服务器、发现设备尚未绑定时，会在小屏幕显示或用声音播报 **6 位验证码**。记下铜豆当时给出的数字。
3. 回到**服务器电脑**的管理页面，打开准备好的角色，进入其设备管理页，点击 **“6位验证码绑定”**。
4. 在“添加设备”窗口输入铜豆当前的验证码，点击 **“确定”**。图中的 `123456` 只是示例，不能用于绑定。
5. 等待绑定完成、语音服务连接就绪。若交付时已经绑定到当前服务器，可能直接进入就绪状态，不会再次给出验证码。
6. **轻触一下铜豆标志**，等设备出现开始听你说话的反馈，再问：“你好，介绍一下你自己。”能听到回答后，再追问一句，确认完整对话能进行。
7. **长按铜豆标志**结束对话。之后可以再尝试说“你好，铜豆”进行语音唤醒。

成功顺序：**无线网络已连接 → 连到服务器 → 验证码绑定 → 能听到语音回答。**

设备联网和语音对话是两件事。能打开铜豆控制台，只能证明本地网络访问正常；完整对话还依赖服务器及角色的三项语音、模型配置。

### 三个地址别混用

| 地址 | 在哪里用 | 用来做什么 |
| --- | --- | --- |
| `http://192.168.4.1/` | 连接铜豆热点的手机 | 首次配网 |
| `http://192.168.1.20:8102`（示例） | 填入铜豆“服务器地址”；以启动窗口为准 | 让铜豆找到服务器 |
| `http://localhost:8102` | 运行服务器的那台电脑 | 注册、配置角色和绑定设备 |

联网后的铜豆本机控制台另用 `http://tongdou.local/` 或铜豆实际地址。服务器电脑和铜豆各有自己的网络地址。

## 5. 卡住了，按现象排查


| 现象 | 按这个顺序做 |
| --- | --- |
| 搜不到 TongDou-Setup | 确认铜豆已通电并打开开关，靠近设备，刷新手机网络列表。设备若已经连上保存的网络，不会走首次配网流程；可先用本机控制台检查。换了网络时，重启后等待原网络连接超时再找热点。 |
| 手机连接热点后说“无互联网” | 保留这条连接，再手动打开 `http://192.168.4.1/`。如果手机自动切走，重新连接并选择仍然使用该网络；必要时暂时关闭移动数据再试。 |
| 浏览器打不开配网页 | 确认手机当前仍连着 TongDou-Setup；完整输入 `http://192.168.4.1/` 到地址栏。暂时关闭影响本地访问的代理或虚拟专用网络软件，再重试。 |
| 保存后又回到配网 | 检查家里网络是否启用 2.4 GHz、名称和密码是否准确，靠近路由器重新保存。不能把铜豆热点名称填作家里的网络名称。 |
| 无线网络已连接，却没有验证码，也不能对话 | 检查服务器是否启动成功、电脑是否休眠、设备地址是否仍与启动窗口一致；确认不是访客网络隔离。手机切回家庭网络后尝试打开该服务器地址，辅助判断本地访问是否通畅。 |
| 绑定失败或一直显示验证码 | 使用铜豆当前的 6 位数字，确认正在正确的服务器、正确角色里绑定。若提示过期，重新获取当前验证码；必要时用电源开关重启铜豆再试。 |
| 已绑定但没有语音回答 | 先轻触标志测试，确认语音服务已连接；再检查角色的语音识别、对话模型、语音合成配置和服务额度。不要只靠反复重新配网解决模型配置问题。 |
| 换了路由器、密码或服务器电脑地址 | 回到已经保存的网络时，开机会自动连接；网络名称或密码变了，需要重新保存。原网络还可用时，从本机控制台重新填写；原网络已不可用时，开关重启，等所有已保存网络尝试完毕、出现配网热点，再按第 3 节配置。服务器电脑地址变了，也要为该网络重新填写新地址。 |

日常重启使用电源开关。**长按铜豆标志是结束对话，不是恢复出厂或进入配网。**

需要求助时，提供：停在哪一步、页面错误文字、屏幕提示、使用的固件和服务器版本。截图遮住家庭网络密码、账号凭据和服务密钥。
