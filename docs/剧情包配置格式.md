# 铜豆剧情包配置格式

## 一句话结论

剧情包不是一堆散规则，而是一个带版本、名称、人格和规则列表的完整配置。

## 第一版格式

当前格式版本：`1`

顶层字段：

- `pack`：剧情包信息。
- `rules`：剧情规则列表。

## pack 字段

```json
{
  "formatVersion": 1,
  "id": "tongdou.default.v1",
  "name": "Default Tong Dou",
  "description": "First built-in pack for warm, cheeky desk companion behavior.",
  "defaultPersonality": "balanced"
}
```

字段说明：

- `formatVersion`：格式版本，用来以后升级兼容。
- `id`：剧情包唯一标识。
- `name`：剧情包名称。
- `description`：剧情包说明。
- `defaultPersonality`：默认人格，可选 `gentle`、`balanced`、`dramatic`。

## rules 字段

每条规则格式：

```json
{
  "enabled": true,
  "event": "reminder-due",
  "allowInQuietMode": false,
  "allowWhenLowBattery": true,
  "minimumPersonality": "gentle",
  "plan": {
    "face": "serious",
    "light": "soft-white",
    "motion": "nudge-forward",
    "voice": "reminder-due-nudge",
    "durationMs": 1200
  }
}
```

字段说明：

- `enabled`：是否启用这条规则。
- `event`：触发事件。
- `allowInQuietMode`：安静模式下是否允许触发。
- `allowWhenLowBattery`：低电量时是否允许触发。
- `minimumPersonality`：最低人格等级。
- `plan.face`：表情动作。
- `plan.light`：灯光动作。
- `plan.motion`：运动动作。
- `plan.voice`：台词编号。
- `plan.durationMs`：剧情建议总时长。

## 生成样例

运行：

```powershell
python firmware/tools/scenario_simulator.py --export-pack outputs/scenario-pack/default.json
```

当前样例文件：

- `outputs/scenario-pack/default.json`

## 边界

第一版只定义格式和导出样例，不急着做完整导入解析。

后续网页编辑器、固件存储、社区剧情包，都应该围绕这个格式继续扩展。
