# V9.4 小智云版固件

这份文档只说明 V9.4 主板连接 `xiaozhi.me` 的独立固件入口。原有 `esp32s3_v94` 继续连接铜豆配套服务器。

## 两个固件入口

| 用途 | 应用构建 | 全新出厂烧录 | 服务器 |
| --- | --- | --- | --- |
| 铜豆正式版 | `esp32s3_v94` | `esp32s3_v94_factory` | 铜豆配套服务器 |
| 小智云版 | `esp32s3_v94_xiaozhi` | `esp32s3_v94_xiaozhi_factory` | `xiaozhi.me` |

两版使用同一套 V9.4 硬件引脚、唤醒模型、分区和固定救援程序。它们是供选择烧录的两个镜像；4 MB 闪存不能同时运行两份正式应用。小智云版使用单独的服务器地址存储项，不会读取原正式版保存的铜豆服务器地址。

## 编译与烧录

在 `firmware` 目录执行：

```powershell
platformio run -e esp32s3_v94_xiaozhi
platformio run -e esp32s3_v94_xiaozhi_factory
```

如果手里已有正常运行的 V9.4 主板，接上数据线、确认串口后，直接烧录小智云应用即可：

```powershell
platformio run -e esp32s3_v94_xiaozhi -t upload
```

这一步只替换应用，不擦除已有的配网信息。想切回原正式版，同样用数据线执行：

```powershell
platformio run -e esp32s3_v94 -t upload
```

全新 V9.4 主板出厂烧录时，确认串口后执行：

```powershell
platformio run -e esp32s3_v94_xiaozhi_factory -t upload
```

该出厂入口同时写入 V9.4 救援程序、中文本地唤醒模型和默认 `en-GB` 本地语言资源。原正式版仍按 [远程固件升级](远程固件升级.md) 中的命令构建和烧录。普通程序镜像位于 `.pio/build/esp32s3_v94_xiaozhi/firmware.bin`，不应改名后放入铜豆服务器的 V9.4 升级目录。

## 首次连接

1. 给设备接入 2.4 GHz 无线网络。在铜豆配网页保存网络信息；小智云版的服务器地址默认是 `https://api.tenclass.net/xiaozhi/ota/`，这是取得配对码和语音地址的入口。
2. 等 OLED 显示六位配对码，在 `https://xiaozhi.me/` 登录后添加设备并输入该码。
3. 设备确认绑定后，会使用服务器下发的安全语音连接地址。说“你好，铜豆”或单击 Logo，检查能否上传语音并听到回复。
4. 如果设备一直没有连上，查看串口中的 `device activation`、`voice websocket` 和 `voice hello` 日志。设备时间尚未同步时会显示 `cloud_time_not_ready`，此时先在配网页校时并等待联网时间同步。

设备编号使用小写网卡地址；客户端编号首次启动时生成，并保存在芯片配置区。普通重新烧录不会更换客户端编号。完整擦除芯片后会生成新编号，需要重新绑定。

## 当前能力边界

- 目标是小智云的配对和基础语音对话。小智云版不向云端公开铜豆专属设备工具；铜豆服务器的提醒正文播报、语言包下发、人格和动作工具不能直接套用到小智云。
- 小智云版出厂只带默认 `en-GB` 本地资源，配网页暂不开放本机语言切换。云端对话语言在 `xiaozhi.me` 设置。
- 本地已有的提醒到期判断仍运行。小智云不提供铜豆的专属提醒播报消息，提醒会走本机异常播报和提示音。
- 小智云返回的固件更新信息不会交给铜豆救援程序。小智云版后续更新先通过 USB 烧录；不能把小智官方通用镜像当作 V9.4 固件安装。
- 云连接使用证书校验。当前内置 DigiCert Global Root G2，若小智云以后更换根证书，须更新固件内的根证书。
- 小智云可能下发 24 kHz 语音，而麦克风上行仍是 16 kHz。固件分别按各自频率编码和解码，并按下行频率驱动喇叭，避免正常连续播放时出现变调。
- V9.4 小智云版目前完成代码接入和编译；配对、麦克风上传、服务器回复、断网恢复及长时间运行仍需 V9.4 实机验收。

## 实机验收清单

1. 编译原 `esp32s3_v94`、小智云应用和小智云出厂入口，核对三个构建均成功。
2. 烧录 V9.4，完成配网；核对六位配对码能在 `xiaozhi.me` 绑定。
3. 检查安全语音连接、`hello` 握手、Logo 单击、中文唤醒、一轮问答和连续三轮对话。
   串口应显示 `voice downlink sample_rate=`；同时听声音是否仍有明显变调。
4. 长按 Logo 结束对话，断开并恢复无线网络，再做一轮问答。
5. 检查本机提醒到期时仍能显示正文和发出离线提示；确认不会安装云端返回的其他设备固件。
