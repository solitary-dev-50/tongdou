# v0.1.2 测试版交付说明

本版为早期测试包，包含正式固件与配套服务器，沿用 v0.1.0 交付结构。只记录实际实现、测试结果和明确待测项。

## 本次范围

- 正式固件升至 0.1.2，避免与已有 0.1.1 包重名。
- IP／本机控制台查询：2026-09-07 项目负责人确认实机已试用通过；电脑端逻辑测试通过。没有把所有异常场景都标成实测通过。
- 记忆后台保留正式 60 秒租约与每 20 秒续期。原测试使用 1 秒真实租约和固定睡眠，容易受线程、磁盘耗时影响；改为受控时钟，仍运行真实线程、续期数据库操作和竞争领取，验证原期限到期后任务不能被抢走。
- 68 项记忆测试和 16 项任务队列测试通过；模型响应在隔离测试中模拟，不等于所有真人对话场景均已验收。
- 多人记忆、跨会话回忆及纠正效果仍待后续实测，不阻塞本次发布，不宣传成完整多人实机验收通过。
- 不扩展到量产级远程升级压力测试，也不声称已经完成。

## 文件结构与烧录

固件包保留一键烧录脚本、工具和许可证、Images 独立镜像、两份完整英文使用说明、中英文烧录指南、分区表和文件校验清单。新增救援程序和 OTA 单应用文件。完整镜像为 4 MB，从 0x0 写入。

| 地址 | 独立镜像 |
| --- | --- |
| 0x000000 | Images/bootloader.bin |
| 0x008000 | Images/partitions.bin |
| 0x00E000 | Images/boot_app0.bin |
| 0x010000 | Images/srmodels.bin |
| 0x100000 | Images/recovery.bin |
| 0x1D0000 | Images/application.bin |
| 0x3D0000 | Images/locale_en-GB.bin |

从 v0.1.0 旧分区首次迁移必须完整 USB 烧录。全量安装清除无线网络、服务器地址、语言、音量、提醒及左右轮方向／力度设置；硬件网卡地址不变。OTA 文件只是正式应用，不能写到 0x0。

板子没有 RESET 复位按钮，日常用电源开关重启。恢复下载模式时，只操作已确认可用的 BOOT 输入并配合重新上电；没有可操作入口时应取得板级步骤，不短接不明焊盘。

## 默认配置与服务器

- 英国英语资源包版本 2，音量 60%，活动提醒 60 分钟、喝水提醒 45 分钟，均默认启用。
- 配网热点 TongDou-Setup，入口 http://192.168.4.1/；联网后使用实际地址进入本机控制台。
- 服务器设备入口默认 8102，以启动脚本显示地址为准；语音 8100、语言资源 8103、声纹本机诊断 8105。
- 配套服务器使用当前源码及 Python 3.11／PowerMem 1.1.7，包含声纹服务、数据库初始化和当前管理端配置字段。
- 模型、语音、向量服务凭据由测试者自行配置；完整管理端以角色选择为准。
- 记忆使用 SQLite 单库 data/powermem_dev.db、集合 memories，开启用户画像。任务和记忆使用同库，计划与回执在同路径附加 .replay.sqlite 的文件中。
- 普通记忆按可信声纹档案和设备隔离，画像按人物保存；未知身份不读写长期记忆。备份需停服务并保留完整 data、上传文件及数据库卷。

## v0.1.2 配套管理端的升级边界

当前 Python 单模块服务已有按版本、大小、摘要下发镜像的实现；完整智控台的设备注册和升级回复尚未完整对齐救援程序所需元数据，不能把这两种部署方式混为已接通。v0.1.2 配套服务器按完整智控台交付，默认采用 USB 烧录，不自动放入远程升级镜像。固件包保留 OTA 单应用文件供兼容环境后续使用，不宣称随包管理端远程升级已验收。本次不扩展修改升级业务。
