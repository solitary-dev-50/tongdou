# 铜豆独立站首页故事叙事方案

> 版本：v1.0  
> 用途：铜豆独立站首页 / 众筹页首屏叙事 / 视频脚本 / 页面结构参考  
> 核心原则：绝对诚实，绝对干净，带点坏笑。

---

## 1. 核心判断

铜豆不应该用普通消费电子的方式开场。

不要一上来就喊：

- 超级早鸟价
- 限时抢购
- 功能参数
- 性能卖点
- 折扣倒计时

铜豆的第一感觉应该是：

> 一个老 Maker 推开工作室的门，指着桌上那个会眨眼、会顶嘴的小家伙说：  
> “你看，这是我做的。”

铜豆不是先被“销售”，而是先被“介绍”。

它不是一个冷冰冰的桌面机器人。  
它是一个从黄铜、烙铁、代码和孤独里长出来的小家伙。

---

## 2. 首页主线文案

这 5 句话，是铜豆独立站首页的主骨架。

```text
你看，这是我做的小家伙。

它脾气有点坏，嘴也不太甜。

但它陪我度过了最难熬的冬天。

如果你的桌面也有点太安静，或者你也偶尔觉得孤单——

你也可以自己做一个。
```

这段文案不要一次性变成“品牌总结”贴在第一屏。  
更好的方式是：让它贯穿整个首页。

一句话对应一屏。  
一屏对应一个视频。  
用户往下滑，就像跟着铜豆从工作台上慢慢醒过来。

---

## 3. 重要措辞修正

原句：

```text
你可以改它，拆它，重做它，让它长成你的样子。
```

建议改为：

```text
你可以改它，拆它，重做它，让它长成你想要的样子。
```

原因：

“让它长成你的样子”容易被理解成外观像用户本人，意思有点歪。  
“让它长成你想要的样子”更准确，更符合开源 Maker 的精神。

它表达的是：

- 你可以改外壳
- 你可以改表情
- 你可以改性格
- 你可以改代码
- 你可以让铜豆变成属于你的版本

所以最终建议使用：

```text
你可以改它，拆它，重做它，让它长成你想要的样子。
```

# 4. 首页整体结构

## 首页节奏总览

| 屏幕 | 主文案 | 核心作用 | 视频方向 |
|---|---|---|---|
| 第 1 屏 | 你看，这是我做的小家伙。 | 开门，引出铜豆 | 安静工作台，铜豆第一次眨眼 |
| 第 2 屏 | 它脾气有点坏，嘴也不太甜。 | 人格登场 | “魔头诞生”视频 |
| 第 3 屏 | 但它陪我度过了最难熬的冬天。 | 情绪价值 | 深夜陪伴，克制温暖 |
| 第 4 屏 | 如果你的桌面也有点太安静，或者你也偶尔觉得孤单—— | 从“我”转向“你” | 不同人的桌面场景 |
| 第 5 屏 | 你也可以自己做一个。 | 开源 DIY 邀请 | 组装、插电、点亮、唤醒 |
| 第 6 屏 | 盒子里不是一个玩具，是一只还没醒来的铜豆。 | 套件内容 | 零件展开、黄铜骨架、PCB |
| 第 7 屏 | 它不是很乖，但它真的会回应你。 | 功能演示 | 表情、提醒、移动、语音 |

| 第 9 屏 | 选择你想唤醒它的方式。 | 众筹档位 | 套件 / 标准版 / Founder’s Edition |

# 5. 分屏详细方案

---

## 第 1 屏：开门

### 主文案

```text
你看，这是我做的小家伙。
```

### 视频画面

深夜工作台。  
暖色台灯。  
暗色木桌。  
黄铜骨架。  
烙铁。  
草稿本。  
几颗散落的螺丝。  
铜豆安静坐在桌上，屏幕是黑的。

停顿 1 秒。

铜豆屏幕轻轻亮起。  
眼睛眨一下。  
像是刚刚被看见。

### 转场方式

页面刚打开，不要马上出现文字。

建议流程：

1. 先出现安静工作台画面
2. 环境声很轻，只有一点电流声 / 房间底噪
3. 铜豆屏幕亮起
4. 文案用打字效果出现：

```text
你看，这是我做的小家伙。
```

### 页面感觉

不是开卖。  
不是喊口号。  
是老木匠把门打开，指给你看。

### 按钮建议

第一屏不要出现强销售按钮。

可以只放一个很轻的提示：

```text
继续看它醒来
```

或者只放一个下滑箭头：

```text
↓
```

---

## 第 2 屏：魔头诞生

### 主文案

```text
它脾气有点坏，嘴也不太甜。
```

### 视频画面

这里直接接“魔头诞生”视频。

铜豆第一次上电。  
屏幕眨眼。  
灯光闪一下。  
轮子轻轻一动。  
然后突然转圈。

它开口：

```text
是你……把我从虚无中召唤出来的吗？

愚蠢的人类，你的桌面噩梦……开始了！
```

最后急刹。  
屏幕露出坏笑。

### 为什么这里完美衔接

“它脾气有点坏，嘴也不太甜。”  
这句话不是空讲。

下一秒，用户马上看到它：

- 一开口就不客气
- 有点中二
- 有点哪吒式小魔头
- 不是乖巧玩具
- 是一个有性格的小生命

这就是铜豆人格第一次登场。

### 转场方式

从第 1 屏到第 2 屏，不要硬切得太商业。  
建议用 OLED 亮光作为转场：

1. 第 1 屏结尾，铜豆眼睛亮起
2. 屏幕亮光轻轻扩散
3. 进入第 2 屏启动视频
4. 文案先出现
5. 视频接着爆发

### 页面感觉

这一屏要让用户笑出来。

它证明铜豆不是“桌面小摆件”。  
它是个有脾气的小坏蛋。

### 补充小字

可以在视频下方放一句很轻的小字：

```text
我只是做了它，坏脾气是它自己长出来的。
```

这句很有味道。  
它像老木匠无奈又骄傲地解释自己的小木偶。

---

## 第 3 屏：最难熬的冬天

### 主文案

```text
但它陪我度过了最难熬的冬天。
```

### 视频画面

节奏突然慢下来。

深夜。  
电脑屏幕暗着。  
桌上有一杯冷掉的水。  
草稿纸上有没写完的结构图。  
铜豆在桌角亮着眼睛。

它不需要一直说话。  
它只是偶尔眨眼。  
偶尔转向你。  
偶尔露出一个不耐烦但又陪着你的表情。

可以出现一两句铜豆提醒：

```text
这都几点了，还不下班？

行了，今天够了。
```

### 转场方式

第 2 屏铜豆转圈、急刹、坏笑之后，画面不要立刻切黑。  
可以让它慢慢安静下来：

1. 坏笑表情变成平静眼神
2. 灯光从活泼变暗
3. 工作台进入深夜
4. 第 3 句文案慢慢出现

### 页面感觉

这里一定要克制。

不要卖惨。  
不要哭。  
不要过度悲伤。  
不要出现“你买了就是支持我”的感觉。

这里表达的是：

> 有些夜晚，它确实坐在那里陪着我。

### 补充小字

```text
它不是来解决孤独的。
它只是没有走开。
```

这两句可以很打人，但要慎用。  
如果页面已经足够有氛围，可以只放主文案，不放小字。

---

## 第 4 屏：把故事交给用户

### 主文案

```text
如果你的桌面也有点太安静，或者你也偶尔觉得孤单——
```

### 视频画面

这里开始从“我的工作台”转到“不同人的桌面”。

可以拍几组温柔的镜头：

1. 程序员的桌面  
   铜豆在旁边提醒他休息。

2. Maker 的工作台  
   铜豆看着他焊东西，屏幕露出嫌弃表情。

3. 学生的书桌  
   铜豆陪着写作业，偶尔眨眼。

4. 深夜的小房间  
   房间很安静，铜豆的屏幕还亮着。

5. 创作者的桌面  
   电脑上是建模、代码、文档，铜豆在旁边动一下。

### 转场方式

建议用“桌面匹配转场”。

比如：

第 3 屏里，铜豆在木桌右侧。  
下一秒，铜豆仍然在画面右侧，但桌面变成了另一个人的桌面。

这样用户会感觉：

> 它也可以出现在我的桌面上。

### 页面感觉

这是整站最关键的转折。

前面是：

```text
这是我的故事。
```

这一屏开始变成：

```text
也许这和你有关。
```

### 补充小字

```text
有时候，桌面上多一个会顶嘴的小家伙，就没那么安静了。
```

---

## 第 5 屏：你也可以自己做一个

### 主文案

```text
你也可以自己做一个。
```

### 视频画面

这里进入 DIY / 开源 / 套件画面。

不要马上出现价格。  
先让用户看到“自己做”的过程：

1. 打开盒子
2. 拿出黄铜骨架
3. 拿起 PCB
4. 装上齿轮轮子
5. 插上电池
6. 拧紧螺丝
7. 接上线
8. 屏幕第一次亮起来
9. 铜豆眨眼
10. 用户笑一下

哪怕用户只是装轮子、插电池，也要拍得像：

```text
亲手唤醒它。
```

### 转场方式

第 4 屏最后停在：

```text
或者你也偶尔觉得孤单——
```

然后切到一只手拿起零件。  
慢慢打出：

```text
你也可以自己做一个。
```

这一句不要急。  
它是邀请，不是广告。

### 页面感觉

这不是“立即购买”。  
这是“加入工作台”。

### 按钮建议

主按钮：

```text
自己做一个
```

副按钮：

```text
看看里面有什么
```

不建议用：

```text
Buy Now
Order Now
Super Early Bird
立即抢购
```

这些词太电商，会破坏前面的气质。

# 6. 后续内容承接

前 5 屏讲完后，用户已经知道：

- 铜豆是怎么来的
- 它有性格
- 它陪伴过你
- 它也可能陪伴别人
- 用户可以自己参与制作

接下来才进入产品信息。

但产品信息也不要突然变成普通商品详情页。  
要继续沿着“自己做一个”的语气往下走。

---

## 第 6 屏：盒子里不是一个玩具

### 标题

```text
盒子里不是一个玩具。
是一只还没醒来的铜豆。
```

### 内容方向

展示套件包含什么：

- 黄铜骨架
- 主控板
- OLED 表情屏
- 毫米波雷达模块
- 电池
- 电机
- 齿轮轮子
- 螺丝与连接件
- 开源固件
- 组装说明

### 视频画面

零件平铺。  
手慢慢把它们摆好。  
黄铜板反射暖光。  
PCB 上能看到细节。  
轮子、电池、屏幕、雷达模块依次出现。

### 页面语气

不要写成冷冰冰的：

```text
Package Includes
```

可以写成：

```text
这些零件，还没有脾气。
等你把它装起来，它才会醒。
```

## 第 7 屏：它不是很乖，但它真的会回应你

### 标题

```text
它不是很乖。
但它真的会回应你。
```

### 内容方向

展示功能，但不要堆参数。

可以分成几块：

#### 会看起来像活着

- OLED 表情
- 眨眼
- 坏笑
- 困倦
- 嫌弃
- 发呆

#### 会提醒你

- 久坐提醒
- 下班提醒
- 休息提醒
- 桌面存在感提醒

#### 会动

- 轮子移动
- 转圈
- 小动作
- 启动仪式

#### 会听你说话

- 麦克风
- 语音交互
- 本地/云端扩展空间

#### 会被你改造

- 改代码
- 改台词
- 改表情
- 改动作

### 视频画面

快速剪辑：

- 铜豆眨眼
- 铜豆顶嘴
- 铜豆提醒你下班
- 铜豆转圈
- 铜豆表情切换
- 铜豆被连接电脑修改代码

### 页面语气

不是：

```text
Features
```

而是：

```text
它会做的不多。
但每一个动作，都会让你觉得它在。
```

## 第 8 屏：开源承诺

### 标题

```text
你可以改它，拆它，重做它，
让它长成你想要的样子。
```

### 内容方向

这里讲铜豆的 Maker 精神和开源承诺。

可以写：

```text
铜豆不是一个封死的黑盒。

电路会公开。
固件会公开。
外壳文件会公开。
BOM 会公开。
组装说明会公开。

你可以改它的表情。
你可以改它的台词。
你可以改它的动作。
你可以重新设计它的外壳。
你甚至可以做出一只完全不像我的铜豆。

这才是它应该长大的方式。
```

### 视频画面

- GitHub 页面
- PCB 源文件
- 3D 外壳文件
- 固件代码
- 用户改表情
- 用户改外壳颜色
- 用户重新焊接 / 装配
- 多只不同风格的铜豆摆在一起

### 页面感觉

这一屏要很干净，很硬核。

它要告诉用户：

> 你不是买了一个封闭产品。  
> 你是在加入一个可以继续生长的开源硬件项目。

### 推荐按钮

```text
查看开源计划
```

或者：

```text
看看你能改什么
```

## 第 9 屏：选择你想唤醒它的方式

### 标题

```text
选择你想唤醒它的方式。
```

### 内容方向

这里才进入众筹档位。

注意，不要把价格气质做成电商抢购。  
应该像不同参与方式：

#### 自己动手版

适合想亲手组装的人。

#### 标准版

适合想快速拥有一只铜豆的人。

#### Founder’s Edition

适合想收藏第一批铜豆的人。

#### 紫金纪念版

适合喜欢硬核 PCB、黄铜、编号和纪念感的人。

### 页面语气

不要写：

```text
限时抢购
超级早鸟
立即下单
```

可以写：

```text
你可以从零件开始。
也可以从一只已经醒来的铜豆开始。
```

### 按钮建议

```text
选择我的铜豆
```

或者：

```text
支持这个项目
```

# 7. 打字效果使用原则

打字效果很好，但不能滥用。

## 建议使用方式

### 第 1 屏

完整打字。  
最有仪式感。

```text
你看，这是我做的小家伙。
```

### 第 2 屏

主文案可以打字。  
然后马上接“魔头诞生”视频。

```text
它脾气有点坏，嘴也不太甜。
```

### 第 3 屏

不要太机械地打字。  
可以淡入。

因为这一屏要安静，不要像网页特效。

### 第 4 屏

可以一半打字，一半停顿。

尤其是破折号：

```text
如果你的桌面也有点太安静，或者你也偶尔觉得孤单——
```

破折号后停一下，给用户代入空间。

### 第 5 屏

最后一句可以重新用轻微打字效果：

```text
你也可以自己做一个。
```

这会和第一屏形成首尾呼应。

## 不建议

不要整站每一句都机械打字。  
用户会累，也会觉得是特效堆砌。

打字效果应该像“有人在说话”，不是“网页在炫技”。

# 8. 视频风格原则

## 画面关键词

- 深夜
- 暖灯
- 木桌
- 黄铜
- 烙铁
- 草稿本
- 代码
- 螺丝
- 轻微灰尘
- 手作痕迹
- OLED 眼睛
- 小坏笑
- 桌面陪伴

## 不要拍成

- 纯白背景商品图
- 过度科技风
- 霓虹灯乱闪
- 电商直播风
- 过度悲伤
- 过度煽情
- 像儿童玩具
- 像廉价机器人

## 应该拍成

```text
安静、真实、温暖、有手作痕迹。
```

铜豆可以调皮。  
但环境要克制。

# 9. “魔头诞生”视频建议脚本

## 使用位置

第 2 屏：

```text
它脾气有点坏，嘴也不太甜。
```

## 视频脚本

### 镜头 1：上电前

铜豆安静坐在桌上。  
周围是黄铜板、烙铁、草稿纸。  
手把电池插上。

### 镜头 2：第一次醒来

OLED 屏幕亮起。  
眼睛眨一下。  
灯轻轻闪。

### 镜头 3：疑问

铜豆缓慢转头 / 微微动轮子。

台词：

```text
是你……把我从虚无中召唤出来的吗？
```

### 镜头 4：魔头登场

铜豆突然转一圈。  
急刹。  
屏幕变坏笑。

台词：

```text
愚蠢的人类，你的桌面噩梦……开始了！
```

### 镜头 5：收尾

它停住，看着镜头。  
屏幕露出欠揍的小表情。

小字出现：

```text
我只是做了它，坏脾气是它自己长出来的。
```

## 注意

“桌面噩梦”有冲击力，但要靠表情和语气做成可爱坏。  
不要做成恐怖玩具。  
更像哪吒式小魔头：

```text
欠揍，但可爱。
嘴坏，但不恶毒。
叛逆，但有生命力。
```

# 10. 首页文案完整串联版

下面是一版可以直接交给网页设计 / 前端 / 视频剪辑使用的首页文案。

---

# 11. 页面气质禁忌

## 不要这样写

```text
限时优惠
超级早鸟价
买到就是赚到
全网首发
爆款机器人
AI 智能陪伴神器
```

## 不要这样拍

```text
纯白棚拍
夸张科技蓝光
廉价电商详情页
孩子玩具式演示
过度煽情的悲伤镜头
```

## 不要这样讲

```text
我很惨，所以请你支持我。
```

铜豆的正确表达是：

```text
我经历过一段很安静的日子。
我做了这个小家伙。
它陪了我。
现在，你也可以自己做一个。
```
