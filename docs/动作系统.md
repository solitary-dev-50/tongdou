# 动作系统

这份文档规定铜豆的电机动作风格和安全边界。

大白话说：

> 铜豆可以嘴上很凶，但身体动作必须怂。

---

## 1. 动作定位

铜豆不是遥控车。

电机动作只负责表达情绪，不负责大范围移动。

核心原则：

- 小幅度。
- 短时间。
- 可中断。
- 默认安全。
- 不撞桌面物品。

---

## 2. 第一版动作列表

| 动作编号 | 名称 | 用途 | 建议时长 |
| --- | --- | --- | --- |
| `motion_stop` | 停止 | 默认安全状态 | 立即 |
| `motion_nod` | 点头 | 确认、奖励 | 100 到 300 毫秒 |
| `motion_tiny_shake` | 小晃 | 上线、撒娇 | 200 到 500 毫秒 |
| `motion_nudge_forward` | 小怼 | 提醒、轻微生气 | 100 到 300 毫秒 |
| `motion_twist` | 原地扭 | 生气、施法 | 200 到 500 毫秒 |
| `motion_cheeky_dance` | 嘴硬小舞步 | 低频彩蛋表演 | 800 到 1000 毫秒 |
| `motion_tired_drop` | 装累 | 完成大动作后 | 300 到 800 毫秒 |

---

## 3. 动作安全规则

硬规则：

1. 上电默认停止。
2. 任何动作必须有限时。
3. 低电量时默认不做电机动作。
4. 安静模式下默认不做夸张动作。
5. 电机异常时禁用所有动作。
6. 不允许长时间堵转。
7. 正式固件里的轮子动作必须经过 `QMI8658A` 陀螺仪补偿，不再直接使用固定左右轮输出。

建议第一版单次动作最长不超过：

```txt
500 毫秒
```

彩蛋动作后续最多不超过：

```txt
1000 毫秒
```

## 4. 动作节奏

### 4.1 点头

感觉：

- 短。
- 稳。
- 轻轻认可。

用途：

- 收到。
- 完成奖励。
- 自学习成功。

### 4.2 小怼

感觉：

- 快进。
- 急停。
- 慢退。

用途：

- 用户忽略提醒。
- 打劫鼠标彩蛋。

注意：

- 默认只前进 1 到 3 厘米。
- 不允许连续怼。

### 4.3 原地扭

感觉：

- 像憋着劲。
- 像小脾气。

用途：

- 生气。
- 施法。
- 装认真。

### 4.4 嘴硬小舞步

感觉：

- 小幅。
- 密集。
- 有节奏。
- 像“我没跳舞，但我认真意思了一下”。

用途：

- 用户主动要求表演。
- 搞怪模式低频彩蛋。

边界：

- 不点名模仿具体人物。
- 不进入政治表达。
- 不前进，不撞桌面物品。
- 总时长控制在 0.8 到 1 秒。
- 安静模式、低电量、重要提醒时不触发。

限幅建议：

- 优先使用高频小幅正反转，让身体产生“扭屁股”的视觉效果。
- 不要做大幅前后摆动，避免铜豆在光滑桌面上跑出原位。
- 左右轮脉冲要尽量对称，单次脉冲短一点，节奏密一点。
- 拍摄时可以在轮胎上套小橡皮圈，或在站位处贴一小块微磨砂隐形胶带。

### 4.5 装累

感觉：

- 动作突然停。
- 表情变累。
- 灯光变弱。

用途：

- 完成施法。
- 完成重任务。
- 邀功。

## 5. 和剧情模块的关系

剧情模块只输出动作编号。

例如：

```txt
ScenarioPlan.motion = MotionAction::NudgeForward
```

动作控制模块负责把编号翻译成电机控制。

正式执行路径：

- 直行动作：用 `QMI8658A` 的 Z 轴偏航数据实时修正左右轮输出，尽量保持直行。
- 原地扭动：允许身体转动，但动作结束后用 Z 轴偏航数据回到动作开始时的角度附近。
- 如果 `QMI8658A` 未就绪，正式动作直接跳过，不退回旧的固定电机输出。

禁止：

- 剧情模块直接写 `digitalWrite()`。
- 电机驱动知道“打劫鼠标剧情”。
- 动作模块自己决定什么时候提醒用户。

---

## 6. 检查清单

新增动作前检查：

1. 是否有最长时间限制？
2. 是否可以被低电量打断？
3. 是否可以被安静模式禁用？
4. 是否可能撞到水杯、鼠标、键盘？
5. 是否需要实物测试再开放？
6. 是否真的提升角色表现？
