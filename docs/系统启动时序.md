# 系统启动时序

本文描述当前新版硬件路线下的启动顺序。

## 一句话原则

先保证安全，再点亮表情，最后启动网络和业务。

## 启动顺序

```text
上电
  -> SystemBootstrap.boot()
  -> App.begin()
       -> 串口日志
       -> HardwareManager.begin()
       -> 电池和充电状态
       -> I2C、OLED 和 QMI8658A
       -> SK6812-EC20
       -> Logo 触摸输入
       -> 电机驱动
       -> 雷达
       -> 麦克风输入
       -> 音频输出
       -> 硬件自检服务
  -> 读取设备语言设置
  -> 校验当前语言资源分区
  -> 时间服务
  -> 提醒存储
  -> MCP
  -> 网页配置服务
  -> 联网并接收服务器语言资源地址
  -> 语言不一致或资源损坏时，在语音空闲状态自动修复
  -> 开机剧情
```

## 安全要求

- 电机默认停止，并保持 `MOTOR_SLEEP / IO42` 低电平，让 `AT8833CT` 处于休眠状态。
- `MOTOR_FAULT / IO37` 作为输入读取 `AT8833CT nFAULT`；低电平表示电机驱动故障，上层必须停止电机并禁止连续重试。
- 灯默认低亮或关闭。
- 音频输出默认不播放。
- 没有拿到时间前，不触发真实提醒。
- 雷达未就绪时，不影响本地提醒。
- `QMI8658A` 未就绪时，不影响 OLED、提醒和网页服务。
- Logo 触摸未就绪时，不影响按钮、网页和提醒。

## 当前启动编排状态

- `main.cpp` 只创建 `SystemBootstrap`，并调用 `boot()` / `run()`。
- `HardwareManager` 负责硬件初始化顺序。
- `/api/status` 会返回 `systemMode`、硬件降级状态和当前保留能力。
- 配网模式仍由 `WebConfigServer` 根据 WiFi 配置决定。
- 当前降级判断先覆盖 OLED、`SK6812-EC20`、麦克风输入和喇叭输出。
- V9 新增的 `QMI8658A` 和 Logo 触摸先进入诊断，不作为系统启动硬依赖。

## 语言资源启动

- 全新出厂设备使用 `esp32s3_factory` 烧录入口，默认 `en-GB` 语言包随固件写入独立 `locale` 分区，因此第一次联网前也能播欢迎、配网和验证码语音。
- 普通开发和升级使用 `esp32s3` 入口，不擦写 `locale` 分区，不会把用户语言改回出厂英语。
- 启动先读取并缓存设备语言，再校验语言包。缺少首次语言设置时只写入一次默认值，不在主循环反复访问不存在的 NVS 键。
- 包缺失、摘要损坏或语言不一致时，本地化语音不回退到另一种内嵌语言；设备联网并完成服务器握手后，在语音空闲状态下载当前语言包并复核。
- 网络故障期间，涉及提醒的异常路径仍保留 OLED 正文和三声实时提示音。

## 音频启动

当前代码里 `AudioOutput` 已经作为 NS4168 的基础输出层。

启动时：

1. 先把 `SPK_CTRL / IO15` 拉高，固定 `NS4168 CTRL` 状态。
2. 初始化 I2S 输出。
3. 配置 `SPK_BCK / SPK_LCK / SPK_DOUT`。
4. 默认不自动播放，避免上电突然出声。
5. 需要实物验证时，通过 `playTestTone()` 播放短测试音。
6. 确认 NS4168 有声音且没有明显爆音。

## 麦克风启动

当前路线中 `AudioInput` 负责 PDM 麦克风基础输入。

1. 初始化 PDM 输入。
2. 配置 `PDM_CLK / PDM_DATA`。
3. 读取一小段原始音频。
4. 每秒打印一次音量诊断。
5. 实物回来后根据串口日志确认麦克风是否有输入。

## 提醒启动

- 存储先启动。
- 时间服务再启动。
- 时间未准备好时，只允许读写提醒，不允许判断到期。
- 时间准备好后，`ReminderManager` 才开始计算到期事件。

## 降级规则

| 模块 | 失败后怎么做 |
| --- | --- |
| OLED | 保留提醒和网页服务，串口提示 |
| QMI8658A | 禁用姿态、敲击和倾倒检测，保留其他功能 |
| Logo 触摸 | 禁用触摸触发，保留按钮、网页和提醒 |
| SK6812-EC20 | 保留提醒和网页服务，串口提示 |
| 电机 | `MOTOR_FAULT / IO37` 低电平或电机初始化失败时禁用动作，只保留表情和声音 |
| 雷达 | 禁用存在感知，只保留提醒 |
| 麦克风输入 | 禁用语音入口，保留网页、MCP 和本地提醒 |
| 音频输出 | 禁用声音，只保留表情、灯光、动作 |
| 时间服务 | 暂停到期判断，允许网页同步时间 |
| 网页服务 | 保留本地提醒和串口日志 |

当前代码中的最小降级能力：

| 能力 | 规则 |
| --- | --- |
| 提醒 | 默认保留 |
| 网页 | 默认保留 |
| 视觉反馈 | OLED 或 `SK6812-EC20` 任一可用就保留 |
| 声音输出 | 喇叭 I2S 初始化成功才可用 |
| 语音输入 | 麦克风 PDM 初始化成功才可用 |

## 开机剧情

开机剧情必须短：

- 表情从睡眼到醒来。
- 灯光暖色低亮。
- 电机轻微动一下。
- 台词不宜太长。

目的不是炫技，而是告诉用户：铜豆醒了。
