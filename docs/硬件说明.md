本文档只描述当前新版硬件路线，是后续固件、文档、测试和开源说明的依据。

当前原理图来源：

- `docs/铜豆原理图_主控与外设_2026-06-20.pdf`
- `docs/铜豆原理图_供电部分_2026-06-20.pdf`

注意：雷达已经从 `HLK-LD2410S` 换成 `LD2412`，当前文字文档和 `docs/引脚定义.txt` 优先级高于旧 PDF 标注。下次导出原理图时需要同步替换旧雷达型号和网络名。

## 一句话结构

铜豆新版硬件由 `ESP32-S3` 直接负责采音、联网、播放、表情、灯光、电机和提醒。

主要模块：

- 主控：`ESP32-S3-MINI-1-N4R2`
- 麦克风：`INMP441`，I2S 数字麦克风
- 功放：`NS4168`，I2S 数字输入单声道 D 类功放
- 显示：0.96 寸 OLED，I2C 接口
- 灯光：`WS2812B-2020` 单颗彩色灯
- 电机驱动：`AT8833CT`
- 雷达：`LD2412` 接口
- 充电：`TP4057`
- 供电：电池、USB 5V、升压 5V、3.3V 稳压

## 主控引脚定义

| 主控引脚 | 网络名 | 用途 | 说明 |
| --- | --- | --- | --- |
| `EN` | `EN` | 主控复位使能 | 低电平复位 |
| `IO0` | `BOOT` | 下载模式 | 烧录时使用 |
| `IO1` | `I2S_LRCLK` | 麦克风 I2S 左右声道时钟 | 接 `INMP441 WS` |
| `IO2` | `I2S_DIN` | 麦克风 I2S 数据输入 | 接 `INMP441 SD` |
| `IO4` | `I2S_BCLK` | 麦克风 I2S 位时钟 | 接 `INMP441 SCK` |
| `IO5` | `I2C_SDA` | OLED 数据线 | 4.7k 上拉到 3.3V |
| `IO6` | `I2C_SCL` | OLED 时钟线 | 4.7k 上拉到 3.3V |
| `IO7` | `LD2412_OUT` | 雷达有人输出 | 默认有人为高电平 |
| `IO8` | `VBAT_ADC` | 电池电压检测 | 分压后进主控 |
| `IO9` | `WS2812_2020` | 彩灯数据线 | 接 WS2812 输入 |
| `IO10` | `RADAR_TX_TO_MODULE_RX` | 主控发给雷达 | 接雷达模块 `RX` |
| `IO11` | `RADAR_RX_FROM_MODULE_TX` | 雷达发给主控 | 接雷达模块 `TX` |
| `IO12` | `SPK_LCK` | 功放 I2S 左右声道时钟 | 接 `NS4168 LRCLK` |
| `IO13` | `SPK_BCK` | 功放 I2S 位时钟 | 接 `NS4168 BCLK` |
| `IO14` | `SPK_DOUT` | 功放 I2S 数据输出 | 接 `NS4168 SDATA` |
| `IO17` | `USB_CHG` | USB 5V 检测 | 分压后进主控 |
| `IO19` | `USB_D-` | USB 数据负线 | 接 Type-C |
| `IO20` | `USB_D+` | USB 数据正线 | 接 Type-C |
| `IO35` | `CHRG` | 充电中状态检测 | 接 `TP4057 CHRG#`，低有效 |
| `IO38` | `AIN1` | 电机 A 路控制 | 接 AT8833 |
| `IO39` | `AIN2` | 电机 A 路控制 | 接 AT8833 |
| `IO40` | `BIN2` | 电机 B 路控制 | 接 AT8833 |
| `IO41` | `BIN1` | 电机 B 路控制 | 接 AT8833 |
| `IO48` | `STBY` | 充满状态检测 | 接 `TP4057 STDBY#`，低有效 |

注意：

- `IO26` 在 `ESP32-S3-MINI-1-N4R2` 上和内部 PSRAM 相关，不作为普通引脚使用。
- `IO45/IO46` 是启动相关脚，不随便分配外设。
- `IO8` 当前用于电池电压检测，属于 ADC1 通道，优先用于联网状态下也要稳定读取的电压检测。
- 固件中的引脚定义必须以本表为准。

## 麦克风电路

麦克风使用 `INMP441` I2S 数字麦克风。

| INMP441 引脚 | 连接 |
| --- | --- |
| `SCK` | `I2S_BCLK / IO4` |
| `SD` | `I2S_DIN / IO2` |
| `WS` | `I2S_LRCLK / IO1` |
| `L/R` | 接地，固定声道 |
| `CHIPEN` | 10k 上拉到 3.3V |
| `VDD` | 3.3V |
| `GND` | GND |

布局要求：

- `INMP441` 是底部进音，PCB 封装必须有声孔。
- 声孔不能被外壳、铜皮、阻焊或丝印挡住。
- 麦克风远离电机、功放、电感和升压芯片。
- `SCK / WS / SD` 建议保留测试点。

## 功放和喇叭

功放使用 `NS4168`，它是 I2S 数字输入单声道 D 类音频功率放大器。

| NS4168 引脚 | 连接 |
| --- | --- |
| `BCLK` | `SPK_BCK / IO13` |
| `LRCLK` | `SPK_LCK / IO12` |
| `SDATA` | `SPK_DOUT / IO14` |
| `CTRL` | 10k 上拉到 3.3V，当前不接主控 |
| `VDD` | `+5V` |
| `GND` | GND |
| `VOP` | `SPK+` |
| `VON` | `SPK-` |

当前决定：

- `NS4168` 暂时保持 `+5V` 供电。
- `CTRL` 暂时保持默认上拉，不再改 GPIO。
- 后续必须实测 3.3V I2S 信号驱动 5V 供电的 NS4168 是否稳定。

## OLED 显示

OLED 使用 I2C 接口。

| 接口 | 主控引脚 | 说明 |
| --- | --- | --- |
| `SDA` | `IO5` | 数据线 |
| `SCL` | `IO6` | 时钟线 |
| `VCC` | 3.3V | 电源 |
| `GND` | GND | 地 |

## WS2812 灯珠

| 引脚 | 连接 |
| --- | --- |
| `VDD` | 3.3V |
| `DI` | `WS2812_2020 / IO9` |
| `DO` | 不使用 |
| `GND` | GND |

注意：

- 灯珠供电没有单独电源开关。
- 深度睡眠前固件应把灯设置为黑色。
- 实物回来后要测灯珠黑色状态下的静态电流。

## 电机驱动

电机驱动使用 `AT8833CT`。

| 主控网络 | 连接 |
| --- | --- |
| `AIN1 / IO38` | A 路输入 1 |
| `AIN2 / IO39` | A 路输入 2 |
| `BIN2 / IO40` | B 路输入 2 |
| `BIN1 / IO41` | B 路输入 1 |

| 驱动输出 | 接口 |
| --- | --- |
| `AOUT1` | 外接电机接口 |
| `AOUT2` | 外接电机接口 |
| `BOUT2` | 外接电机接口 |
| `BOUT1` | 外接电机接口 |

当前决定：

- `nSLEEP` 通过 10k 上拉到 3.3V，电机驱动默认常开。
- `nFAULT` 通过 10k 上拉到 3.3V，当前未接主控。
- 第一版靠固件限制动作时长，避免长时间堵转。

## 毫米波雷达接口

雷达使用 `LD2412`，接口按 6 针处理：

| 接口脚位 | 网络 | 主控引脚 |
| --- | --- | --- |
| 1 | `LD2412_OUT` | `IO7` |
| 2 | `RADAR_TX_TO_MODULE_RX` | `IO10` |
| 3 | `RADAR_RX_FROM_MODULE_TX` | `IO11` |
| 4 | `3V3` | 供电 |
| 5 | `GND` | 地 |
| 6 | `G` | 地 |

注意：

- `RADAR_TX_TO_MODULE_RX` 接雷达模块 `RX`，也就是主控发数据给雷达。
- `RADAR_RX_FROM_MODULE_TX` 接雷达模块 `TX`，也就是雷达发数据给主控。
- `LD2412_OUT` 默认有人为高电平、无人为低电平，后续可通过串口配置。
- `LD2412` 可选 5V 或 3.3V 供电，铜豆当前按 3.3V 供电处理，不要同时接 5V 和 3.3V。
- 实物回来后必须确认串口方向、输出电平和检测距离参数。

## 充电和电量检测

充电芯片为 `TP4057`。

| TP4057 引脚 | 网络 | 说明 |
| --- | --- | --- |
| `VCC` | `USB_5V` | USB 输入 |
| `BAT` | `VBATT` | 电池端 |
| `GND` | GND | 地 |
| `PROG` | `PROG` | 充电电流设置 |
| `CHRG#` | `CHRG` | 充电中，低有效 |
| `STDBY#` | `STBY` | 充满，低有效 |

状态检测：

- `CHRG` 通过 10k 上拉到 3.3V，并接 `IO35`。
- `STBY` 通过 10k 上拉到 3.3V，并接 `IO48`。
- 固件读取时要按低有效处理。

电量检测：

- `VBAT_ADC / IO8` 通过 100k/100k 分压检测电池电压。
- `USB_CHG` 通过 100k/150k 分压检测 USB 5V。

## 供电链路

主要电源：

- `VBATT`：锂电池电压。
- `VBAT_5V`：电池升压后的 5V。
- `USB_5V`：Type-C 输入 5V。
- `+5V`：自动切换和开关后的系统 5V。
- `3V3`：由 `+5V` 经 LDO 转换得到。

当前结构：

```text
电池 -> 升压 -> VBAT_5V
USB  -> USB_5V
VBAT_5V / USB_5V -> 自动切换 -> 开关 -> +5V -> 3V3
```

注意：

- `NS4168`、电机驱动、3.3V LDO 都接在开关后的 `+5V`。
- `AP2112` 从 5V 降到 3.3V，实物回来后要测 WiFi 工作时温升。
- 电机和功放都是噪声源，布局时要让麦克风远离它们。

## 打样前检查清单

- `INMP441` 封装声孔方向正确。
- `INMP441` 远离电机、功放和升压电感。
- `NS4168` 封装脚位和喇叭正负确认。
- `NS4168` 5V 供电时，3.3V I2S 信号需要实测确认。
- `TP4057 CHRG/STBY` 是低有效，不能按高有效写固件。
- `USB-C CC1/CC2` 下拉电阻正确。
- `ESP32-S3` 启动脚没有被外部电路拉错。
- 所有外接座脚序和丝印方向一致。
