# TongDou Hardware

This directory contains the public TongDou hardware materials that are ready
for release.

## Contents

- `pcb/tongdou-pcb-v8/` - Verified TongDou PCB v8 design package
- `mechanical/` - Mechanical files that are ready for public release

## Current Scope

The PCB v8 package includes editable PCB source, schematic PDFs, Gerber files,
BOM, and pick-and-place data.

The mechanical directory currently includes the brass side-plate cutting file.
Additional original fixture files, CAD/STEP files, CNC notes, and build media
will be released progressively.

This directory is not a complete TongDou manufacturing kit yet. TongDou is
being open-sourced step by step by one independent maker.
