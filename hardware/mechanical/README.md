# TongDou Mechanical Files

This directory contains mechanical files that are ready for public release.

## Available Now

- `TongDou_Brass_Frame_1mm_H62_RevA.dxf` - H62 brass side-plate cutting file

The brass side plates are part of TongDou's compact brass-and-PCB mechanical
form.

## Planned Materials

The original TongDou soldering and alignment fixture is part of the open
hardware design. Fixture CAD/STEP files, key dimensions, CNC notes, installation
media, and usage material will be released progressively after they are checked
and prepared.
