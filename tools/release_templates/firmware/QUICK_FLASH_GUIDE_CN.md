# 铜豆 v0.1.2 一键烧录

1. 完整解压本包，用数据线连接铜豆，关闭串口监视器。
2. 双击 `FLASH_TONGDOU.bat`，确认全新安装。
3. 脚本优先列出 USB 串口。多个设备时通过插拔确认铜豆对应哪一项，再按编号选择。
4. 等待 `SUCCESS`。没有正常重启时，用电源开关断电再上电。
5. 启动配套服务器 v0.1.2，记下启动脚本显示的设备服务器地址。
6. 手机或电脑连接 `TongDou-Setup`，打开 `http://192.168.4.1/`。
7. 填写无线网络和服务器地址（默认端口 8102），绑定激活码，配置自己的语音和模型服务。
8. 检查语言、音量、提醒和左右轮方向／力度设置。

完整 4 MB 安装会清除无线网络、服务器地址、语言、音量、提醒和电机设置；硬件网卡地址不变。v0.1.0 旧分区首次迁移必须使用完整镜像。

当前板子没有复位按钮。进入下载模式时，只有在板上存在可操作的 BOOT 输入且已确认位置的情况下，才将其拉低并用电源开关重新上电，再释放；没有可操作入口时请取得该板专用恢复步骤，不要短接不明焊盘。

`OTA/` 是远程升级用的单应用文件，不能写到 0x0。详细功能与限制见随包说明。
